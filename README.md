# Love You 💝

A special Android mobile application - a small gift for someone you love.

## About
This is a heartfelt Android APK application created as a gift. It's designed to express love and appreciation in a unique way.

## Features
- 💝 Personalized experience
- 🎨 Beautiful UI
- ❤️ Heartfelt messages
- 📱 Mobile-friendly

## Getting Started

### Requirements
- Android Studio
- JDK 8 or higher
- Android SDK

### Installation
1. Clone the repository
```bash
git clone https://github.com/xzrxzrxzr7/love-you.git
cd love-you
```

2. Open in Android Studio
3. Build and run the APK

## Customization
This application requires personal modifications to make it truly special:
- Update messages and content
- Customize colors and themes
- Add photos or personal touches
- Modify animations and effects

## Building APK
```bash
./gradlew build
```

The APK will be generated in `app/build/outputs/apk/`
